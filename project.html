Problem: Forgotten Context & Static AI

Standard AI chatbots reset memory between sessions or drop background context once threads get long. They also lack access to live internet data or custom uploaded user documents.

Memory Erasure Static Information No Custom Knowledge

Solution: BOT-O-BRAIN Architecture

BOT-O-BRAIN combines active thread session state with automated long-term vector fact extraction in Chroma DB. It executes agentic tools (Web Search & Python REPL) and queries uploaded documents seamlessly.

System Foundation

Core Architecture Pillars

1. Dual-Memory System

Short-Term: LangGraph's MemorySaver maintains ongoing conversation threads per session.
Long-Term: Durable user facts are extracted by a fast background LLM and stored as embeddings in Chroma DB tagged per user.

MemorySaver ChromaDB MiniLM-L6-v2

2. Document RAG Engine

Ingests PDFs, CSVs, TXT, Markdown, and Python code files. Uses RecursiveCharacterTextSplitter (800-char chunks, 150-char overlap) indexed in a vector store for accurate context retrieval.

PyPDF Chunking Semantic Search

3. Agentic Tools Suite

Empowers the assistant with live internet search via DuckDuckGo and safe Python code execution for complex math algorithms, financial metric calculations, and string transformations.

DuckDuckGo Python REPL Tool Node

4. Multi-Model Resilience

Automatic failover hierarchy ensuring zero downtime: Groq llama-3.3-70b-versatile (Primary) $\rightarrow$ OpenRouter $\rightarrow$ Cohere $\rightarrow$ OpenAI gpt-4o-mini.

Groq Llama 3.3 Failover Hierarchy 99.9% Uptime

5. Multi-Tenant Security

Salted SHA-256 password hashing, 6-digit SMTP Email OTP verification, and strict user isolation scoping across SQLite tables and Chroma metadata filters.

SHA-256 Email OTP Metadata Scoping

6. Multimodal Vision Support

Detects image file attachments automatically and routes prompts to vision-capable LLM models (e.g. llama-3.2-90b-vision-preview / Gemini) for visual analysis.

Vision LLM Image Attachments OCR & Analysis

Deployment & Setup

Quick Start Launch Guide

Launch BOT-O-BRAIN Locally 

# 1. Clone the repository & enter workspace
git clone https://github.com/srivastava071/BOT-O-BRAIN.git
cd ProjectMemoryChatbot

# 2. Install dependencies
pip install fastapi uvicorn langgraph langchain-core langchain-openai \
            langchain-chroma chromadb python-dotenv langchain-huggingface \
            sentence-transformers pypdf requests duckduckgo-search

# 3. Configure API key in .env file
GROQ_API_KEY=gsk_your_groq_api_key_here

# 4. Start the FastAPI server
python server.py

Once launched, open http://localhost:8000 in your browser to access the live chatbot!
